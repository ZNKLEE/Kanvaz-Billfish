# 中文素材板修改说明

基于 MIT 授权的 Kanvaz 9.8.2，分支 `billfish-zh-cn`。

1. 添加集中中文字典和运行时语言切换，翻译内置界面与原生对话框。
2. 添加独立只读 Billfish 素材库连接、搜索、目录筛选、分页、多选、预览和批量加入画布。
3. 添加基于素材库 UUID 和十进制字符串素材 ID 的关联卡片；处理文件移动、丢失和重新关联。
4. 添加旋转交互、旋转后的范围计算、可见图片按需加载、有限预览缓存。
5. 添加独立保存目录、当前素材板导出、明确选择的完整打包导出，保护素材库路径。
6. 使用独立应用 ID、用户数据目录和文件打开注册；关闭上游自动更新，保留上游 MIT 与第三方许可证。
7. 添加单元、生产 IPC、真实 Electron UI、性能和 Windows 安装卸载检查。

开发仅修改本项目文件。未修改 `D:\Billfish`、`D:\本地资源库` 的程序、数据库、原图或配置；写入测试只针对项目内生成的测试库。

完整变更文件及基线/交付 SHA-256 见 `MODIFICATION_MANIFEST.json`。卸载独立应用即可移除程序；素材板文件和用户设置由用户自行保留或删除。便携包也使用独立 AppData 配置，具体位置见使用说明。
