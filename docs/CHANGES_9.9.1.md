# 9.9.1 播放、帧笔记与缓存设置

- 常见 8 位 PNG/JPEG/WebP/BMP 序列直接交给浏览器解码，预读窗口最多 10 帧，并按 64 MiB 原始像素预算缩小；不再为这些图片每播放一帧启动一次 FFmpeg。其他格式继续使用精确帧解码服务。
- 汉化改为扫描发生变化的局部区域；播放器和帧笔记区域不参与重复扫描。缓存目录整理不再在每帧解码后同步执行；输入笔记时合并短时间内的保存，关闭时等待保存完成。
- 点击笔记正文、缩略图或空白处即可选中整条；每条笔记直接显示“删除整条”。编辑区也保留“删除整条笔记”。选中笔记卡后可按 Delete 删除；搜索和筛选状态在切换笔记时保留。
- 只选中一个视频或序列卡片时，D 上一帧、F 下一帧，定位时暂停播放。输入文字、组合输入或按下 Ctrl/Alt/Shift 时不触发。未选择视频时 F 仍为适应画布，Shift+F 仍为适应选中。
- 顶部“素材板设置”新增“独立缓存目录”。选择目标文件夹后自动使用其 Kanvaz-Cache 子目录，重启后生效。媒体预览、解码缓存、代理临时文件和浏览器缓存跟随该设置。配置、帧笔记和附件仍保存在原用户数据目录，项目和源素材不移动。
- 切换目录不会自动删除原缓存。自定义目录失效时回到默认缓存目录，并在设置中显示原因。

大尺寸、压缩复杂的图片以及慢速磁盘仍可能限制首次解码速度。精确视频跳帧仍按真实 PTS 索引解码；长片从头解码的既有耗时未在本轮改写。
