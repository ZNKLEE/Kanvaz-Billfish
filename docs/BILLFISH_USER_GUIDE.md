# Kanvaz Billfish 中文素材板

独立 Windows 桌面应用，基于 Kanvaz 9.8.2。不会在 Billfish 原生窗口添加标签或菜单，也不修改 Billfish 安装文件。

## 启动与素材库

启动 `Kanvaz-Billfish.exe` 或便携版 EXE。默认简体中文。
首次启动只读连接 `D:\本地资源库`。目录不存在时，通过「Billfish 素材库」选择包含 `.bf\billfish.db` 的资源库根目录。
首页侧栏和画布顶部均有「Billfish 素材库」入口。

左侧选择文件夹；右侧按文件名搜索或图片格式筛选。每页最多 80 张。
Ctrl 单击多选，Shift 单击连续选择；「全选当前结果」选择当前页。
双击图片打开高清预览；右键或「添加到素材板」批量加入画布。
新增图片按当前视角排列，避开已有卡片。之后可自由拖动、等比缩放、框选、调整层级。
在属性面板的「变换」中修改旋转角度，支持拖动数值标签连续调整。

「刷新」重新读取索引；下拉框切换已经连接的库；「连接素材库」添加新库。
整个资源库目录搬迁后，选中原库并点击「重新定位素材库目录」，选择新位置，以保留扩展侧 UUID。
复制出来的另一套资源库应使用「连接素材库」获得独立 UUID。

## 保存和恢复

「素材板设置」→「默认素材板保存目录」→「选择文件夹」。保存位置必须位于 Billfish 库以外。
Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+O 打开，原有快捷键不变。
正常 `.kanvaz` 保存只记录 Billfish 库 UUID、十进制字符串素材 ID、路径辅助信息和布局；不重复嵌入原图或预览。
原有普通图片卡片仍按 Kanvaz 原格式嵌入保存。

一个文件可以包含多个素材板。需要独立文件时，切换到目标素材板，选择「素材板设置」→「单独保存当前素材板」。
需要迁移到另一台电脑而不依赖 Billfish 库时，明确选择「打包导出完整素材板」；此操作将原图嵌入新的 `.kanvaz` 包，不改动来源文件。
缺失的素材不能打包，应先重新关联。

自动保存生成独立用户数据目录中的恢复副本；重启后显示恢复提示。
正常保存的最后一个文件会在下次启动时重新打开；恢复副本优先提示恢复。
保存使用临时文件和原子替换，现有文件的外部修改会触发覆盖冲突提示。

## 素材关联与丢失

同一库中的素材移动或重命名后，重新打开素材板或刷新索引，程序按素材 ID 查询新位置。
素材或资源库不存在时，保留原卡片和布局，显示「素材已丢失」。点击「重新关联素材」，在素材库中选择替代素材。
在素材板删除卡片只删除引用；不删除、移动或编辑 Billfish 原图、标签、分类或数据库。

## 从外部程序打开

可将本程序设置为 Windows「打开方式」中的应用，或使用命令行：

```powershell
& '安装位置\Kanvaz-Billfish.exe' 'D:\本地资源库\文件夹\图片一.png' 'D:\本地资源库\文件夹\图片二.jpg'
```

已经运行时，激活现有窗口并加入图片。3 秒内完全相同的一组路径视为重复请求。
已登记 Billfish 库内的图片保留关联；外部图片采用原有嵌入方式，不写入 Billfish 库。
如果 Billfish 当前版本提供外部程序打开配置，可将目标设置为本 EXE。没有证实的 Billfish 原生右键菜单扩展不宣称已实现。

## 设置和独立性

「素材板设置」可切换简体中文与 English，并配置库和保存目录。
用户数据目录：`%APPDATA%\Kanvaz-Billfish-ZhCN`。
连接记录保存在 `billfish\settings.json`；UUID 只由本程序管理，不写回资源库。
SQLite 连接为 `readOnly: true` 且 `PRAGMA query_only=ON`，不加载 Billfish 私有全文搜索扩展。
缩略图路径是当前 Billfish 版本的观察结果；没有缓存时尝试原图预览。某些 TIFF/特殊编码格式可能不能预览，会保留引用并显示提示。
主进程预览缓存上限 32 MB、加载并发 4；图库分页，画布按可见区域加载预览。

## 卸载与更新

安装版使用 Windows 已安装应用中的卸载入口。便携版直接移走 EXE。
卸载仅移除本定制版文件和自身 OpenWith 注册，不改变原版 Kanvaz 默认关联。
用户素材板自行保管；用户数据目录可另外备份。删除此目录会丢失库 UUID 登记，建议保留或迁移。
不自动接收上游更新。升级定制版前备份用户数据和素材板；Billfish 更改数据库结构或缓存格式时可能需要更新连接器。

## 开发与验证

源码：`D:\本地资源库\插件\Kanvaz-Billfish`，分支 `billfish-zh-cn`。保留 MIT 原许可证。
工具启动：`.tools\npm.cmd start`；打包：`.tools\npm.cmd run build:win`。
测试：`lint`、`validate`、`test:format`、`test:plugins`、`test:billfish`；真实 Electron 测试：`node test\billfish-ui-test.js`。
测试样本和结果位于 `.tools`；真实 Billfish 库仅只读访问。
# 视频和图片序列

视频素材（MP4、WebM、MOV、MKV、AVI）以本地文件引用方式加入，默认暂停；播放时可以拖动进度、静音或循环。浏览器不支持原编码时，Kanvaz 会尝试使用随包 FFmpeg 生成 WebM 代理，原始视频不被改动。

多选图片或一次拖入一组图片时，文件名末尾的数字可被识别为序列帧号。至少两帧会询问按序列播放或作为独立图片导入；帧率可设为 1–120 fps，默认 24 fps。缺少的帧会跳过并提示，重复编号阻止该组建立为序列。序列卡片上的 fps 按钮可再次调整播放帧率。代理和序列播放缓存位于 Kanvaz 用户数据目录，不会写回来源素材。

Billfish 浏览器可在图片和视频之间切换筛选；视频缩略图按需生成。左侧目录箭头控制展开，目录名称用于筛选，顶部提供全部展开和收起。画布工具栏的「图片信息」按钮可显示或隐藏图片名称及尺寸说明，设置会记住。

构建 Windows 版需要联网下载并校验 BtbN FFmpeg 8.1 LGPL shared 固定归档：`npm run prepare:ffmpeg`。许可证随安装包位于 `resources/ffmpeg/LICENSE.txt`。更换版本前应更新来源和 SHA-256。
