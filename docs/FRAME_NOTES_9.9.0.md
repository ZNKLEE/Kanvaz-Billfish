# Kanvaz Billfish 9.9.0 帧功能

本版保留原有汉化、Billfish 只读关联和旧项目读取。旧项目首次保存前，在原文件旁保留 `.pre-9.9.0.bak` 副本。

## 序列导入

多选图片或拖入文件夹，检查分组、首尾编号、缺帧与帧号字段，选择“作为序列”，再设置帧率。单张图片先选择“作为单图”或“识别同目录序列”。帧号默认优先选择最右侧可形成序列的数字字段，也能手动修正。

缺帧确认后按已有文件连续播放；重复编号、坏帧和混合尺寸会阻止该组导入，不会自动补帧、拉伸、裁切或丢帧。清单固定保存；源目录变化后需要明确确认重新扫描。

新序列按导入开始时的可用视口放置，多个序列紧凑排布。导入期间移动视图不会被抢回，可点击下方“已导入…定位素材”。播放器内完整显示源画幅，透明边不裁切。

## 帧与播放

内部索引从 0 开始；界面播放帧从 1 开始；源帧号单独显示。例如源编号 1001、1002、1004，对应播放第 1、2、3 帧。

支持首末帧、前后逐帧、输入播放帧号回车、源帧查找、循环、倍速、全屏和棋盘格/黑底/白底。播放器获得焦点时使用左右方向键、空格、Home、End；笔记输入不触发画布或播放快捷键。

序列支持 1–120 fps，常用 12、24、25、30、48、50、60，记住上次选择。23.976、29.97、59.94 分别解释为 24000/1001、30000/1001、60000/1001，也可直接输入分数。修改播放帧率不改变笔记所指的源画面。

视频先后台建立展示顺序的实际 PTS 索引，完成后显示准确总帧数。VFR 显示平均帧率并明确标识；缺失、重复、非递增的 PTS 会报错。暂停、逐帧和跳转使用本地解码出的目标帧，呈现后才更新编号；不是以秒数乘平均帧率冒充逐帧。

## 图文帧笔记

点击“＋笔记”暂停并锁定已呈现帧。可输入多行文字、在编辑区 Ctrl+V 粘贴图片、拖入图片、点击“添加图片”或“插入当前帧截图”。图片支持预览、放大、删除和左右排序；同帧允许多条笔记。

点击笔记或时间轴标记会暂停并回跳；编辑区明确显示锁定的播放帧与源编号。支持全部/当前帧/含图片筛选、搜索和上下条笔记。同一资产的多个画布实例共享笔记。

状态“已保存”表示本地写入成功；失败时保留编辑内容，点击“重试保存”。关闭前会等待笔记保存。附件复制到本地管理目录，不依赖剪贴板、临时路径或外部原图片。清理媒体缓存不会删除笔记和附件。

笔记与图片同时包含在保存的 `.kanvaz` 项目中，并在应用用户数据目录 `frame-notes` 内原子保存。默认目录是 `%APPDATA%\Kanvaz-Billfish-ZhCN\frame-notes`。备份项目文件，或“导出全部/导出选中”生成包含 Markdown、JSON 和相对路径图片的 ZIP。导入时检查素材 ID、源版本与笔记 ID，避免重复导入和错误关联。

源媒体丢失后仍能查看已保存文字和图片；使用“重新关联”找回媒体。源内容或清单版本改变时，旧笔记会标记“待核对”，不能直接跳到新版本。核对画面后用“已核对此帧”明确重新绑定。

## 解码与边界

序列直接逐帧解码为 PNG 预览，保留 Alpha，不依赖 VP9 代理成功。兼容代理路径探测 Alpha 后，透明使用 `yuva420p`，不透明使用 `yuv420p`，不使用 `-strict experimental`。源图不修改。

已验证常见 PNG RGB/RGBA/灰度/灰度 Alpha、JPG、BMP、TGA RGB/RGBA 未压缩/RLE、单页 TIFF RGBA 8/16 位。16 位源图生成 8 位预览，保留原文件，不声称实现高位深色彩管理。多页 TIFF 和 BigTIFF 明确拒绝；EXR/DPX 仍取决于随包解码器与具体文件，不列为本轮已验证格式；特殊 CMYK/HDR 变体未全面验证。

视频精确跳转从源视频解码到指定展示帧，长片首次跳转可能较慢；可取消，已解码帧可缓存。序列正常播放按时钟推进，性能不足时可能跳过显示帧；暂停和笔记仍绑定准确源帧。

精确帧服务中的压缩帧缓存上限为 64 MiB，该服务的解码/探测进程最多同时 3 个，解码缓存可重建。单组最多 20000 张图片；单张笔记附件最多 32 MiB。普通媒体导入沿用原有单文件 500 MiB 限制；原生不兼容视频的 WebM 代理另有 2 GiB 上限。索引能力与原生实时播放能力不同，不能承诺所有解码器支持的文件都能实时播放。
